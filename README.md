# Spacio – Workspace & Event Space Platform

Spacio is a modern web platform designed to connect businesses and individuals with office spaces, coworking areas, meeting rooms, and event venues — all in one place. The project focuses on clean UI, smooth user experience, and clarity in space discovery.

---

## 🚀 Project Overview

Finding the right workspace or event space is often time-consuming and unorganized. Spacio solves this problem by providing a single digital platform where users can explore, list, and discover spaces easily, while property owners can reach the right audience.

---

## ✨ Features

- Category-based navigation for different space types  
  (Office Space, Coworking, Meeting Room, Event Space, etc.)
- Clean and modern homepage layout
- “Amazing Workspaces” section highlighting premium spaces
- About Us page explaining platform vision and trust
- Contact Us page for business and partnership inquiries
- Step-based space listing form for property owners
- Responsive design for all screen sizes

---

## 🛠️ Tech Stack

- **Frontend:** HTML, CSS, JavaScript  
- **Styling:** Modern minimalist UI design principles  
- **Design Reference:** Interior & workspace-focused layouts
